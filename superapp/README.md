# فرانت‌اند وب سوپراپلیکیشن یولدا

این بسته نسخه وب تعاملی، واکنش‌گرا و قابل‌نصب (PWA) یولداست. پروژه با HTML، CSS و JavaScript خالص ساخته شده، وابستگی خارجی و مرحله Build ندارد و مستقیماً روی هاست استاتیک اجرا می‌شود.

## اجرای محلی

در پوشه پروژه یک وب‌سرور محلی اجرا کنید:

```bash
python -m http.server 8080
```

سپس `http://localhost:8080` را باز کنید. اجرای مستقیم `index.html` نیز ممکن است، اما Service Worker فقط روی HTTP/HTTPS فعال می‌شود.

## امکانات اصلی

- طراحی کامل RTL و Mobile-first برای موبایل، تبلت و دسکتاپ
- ۹۰ مسیر قابل رندر شامل صفحات مشتری و پنل‌های فروشنده، پیک و عملیات
- سه سبد مستقل برای غذا، سوپرمارکت و داروخانه
- جست‌وجوی سراسری، علاقه‌مندی، سفارش مجدد و رهگیری سفارش
- تسویه‌حساب چندمرحله‌ای، کیف پول، تراکنش‌ها، باشگاه مشتریان و دعوت دوستان
- نسخه داروخانه، بارگذاری نسخه و مشاهده وضعیت بررسی داروساز
- پشتیبانی تیکتی و گفت‌وگو، تنظیمات امنیت، اعلان و زبان
- تم روشن/تیره، Local Storage و Service Worker
- لایه API آماده اتصال با timeout، مدیریت خطا، idempotency و نشست OTP
- کتابخانه قابل جست‌وجوی هر ۱۴۸ آیکون در مسیر `#/icons`

## پیشنهاددهنده هوشمند یولدا

فایل `assets/js/recommender.js` یک موتور پیشنهاددهنده محلی و توضیح‌پذیر است که بدون API خارجی کار می‌کند. ورودی طبیعی فارسی و پرسش‌نامه را با داده‌های واقعی کاتالوگ ترکیب می‌کند و این سیگنال‌ها را در رتبه‌بندی دخالت می‌دهد:

- بودجه و زمان تحویل
- سبک و حال‌وهوای غذایی
- رژیم غذایی، کالری و میزان تندی
- امتیاز، محبوبیت و موجودی
- شباهت متنی و معنایی ویژگی‌ها
- بازخورد مثبت یا منفی کاربر
- تنوع نتایج برای جلوگیری از پیشنهادهای تکراری

برای هر پیشنهاد، درصد تطابق و دلیل انتخاب نمایش داده می‌شود. تاریخچه و بازخورد روی همان دستگاه ذخیره می‌شوند. برای نسخه سروری می‌توان همین رابط داده را به API یا مدل ML متصل کرد.

## فونت و هویت بصری

فونت اصلی در `assets/css/tokens.css` با نام `Dana` تعریف شده است. به‌دلیل مجوز تجاری، فایل فونت داخل بسته نیست و مرورگر از fallbackهای فارسی استفاده می‌کند. فایل‌های مجاز دانا را در `assets/fonts` قرار دهید و `@font-face` را به ابتدای `tokens.css` اضافه کنید.

رنگ فعلی بنفش `#5E1A84` و زرد `#FFC400` است. همه رنگ‌ها، شعاع‌ها، سایه‌ها و تایپوگرافی در `tokens.css` متمرکز شده‌اند. جای لوگوی نهایی با `.brand-placeholder` مشخص است تا پس از دریافت فایل لوگو جایگزین شود.

## اتصال به بک‌اند

این تحویل، فرانت‌اند کامل است؛ OTP، پرداخت بانکی، نقشه، Push، آپلود واقعی فایل و داده‌های عملیاتی فعلاً با داده نمایشی اجرا می‌شوند. نقطه‌های اتصال UI در `assets/js/app.js` متمرکزند و می‌توان آن‌ها را به API واقعی جایگزین کرد.

برای اتصال، در `assets/js/config.js` مقدار `mode` را روی `live` و `apiBaseUrl` را روی آدرس HTTPS بک‌اند قرار دهید. قراردادهای احراز هویت، سفارش و پشتیبانی در `assets/js/api.js` آماده شده‌اند. Access Token فقط در Session Storage نگه‌داری می‌شود و Refresh Token برای پیاده‌سازی سروری باید به‌صورت HttpOnly Cookie صادر شود.
