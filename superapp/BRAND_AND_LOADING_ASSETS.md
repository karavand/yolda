# راهنمای جای‌گذاری لوگو، فونت و لودینگ یولدا

همه فایل‌های هویت بصری باید محلی باشند؛ از لینک موقت Figma یا CDN برای نسخه نهایی استفاده نکنید.

## ۱) لوگو

لوگوی تحویلی یولدا اکنون با نام `assets/brand/yolda-logo.png` فعال است و در هدر، سایدبار، لودینگ و favicon استفاده می‌شود. نسخه فشرده هدر از همان فایل و با برش CSS ساخته شده تا نشان واقعی برند جای placeholder قبلی را بگیرد.

برای تحویل برداری آینده، فایل‌ها را با نام‌های زیر در `assets/brand/` قرار دهید و مسیرهای `assets/js/config.js` را به آن‌ها تغییر دهید:

| فایل | کاربرد | فرمت پیشنهادی |
| --- | --- | --- |
| `yolda-symbol.svg` | نشان واقعی یولدا در هدر موبایل، سایدبار و فضاهای کوچک | SVG با پس‌زمینه شفاف |
| `yolda-symbol-light.svg` | نسخه روشن همان نشان برای سایدبار تیره | SVG با پس‌زمینه شفاف |
| `yolda-logo.svg` | لوگوتایپ کامل برای صفحات بازاریابی | SVG با پس‌زمینه شفاف |
| `yolda-logo-light.svg` | نسخه روشن روی زمینه بنفش/تیره | SVG با پس‌زمینه شفاف |
| `favicon.svg` | آیکون تب مرورگر | SVG مربع با `viewBox` |
| `apple-touch-icon.png` | نصب روی iPhone/iPad | PNG، اندازه ۱۸۰×۱۸۰ |
| `pwa-192.png` | آیکون نصب PWA | PNG، اندازه ۱۹۲×۱۹۲ |
| `pwa-512.png` | آیکون نصب و Splash Screen | PNG، اندازه ۵۱۲×۵۱۲ |

در فایل SVG، نوشته‌ها را به Path تبدیل کنید تا وابستگی به فونت نداشته باشد. فضای خالی دور نشان را حذف و `viewBox` را دقیق تنظیم کنید. مطابق هویت یولدا، در فضاهای آیکونی فقط نشان واقعی و بدون نوشته استفاده می‌شود.

پس از تحویل دو فایل PWA، مسیر آیکون‌های `manifest.webmanifest` را از آیکون موقت فعلی به `assets/brand/pwa-192.png` و `assets/brand/pwa-512.png` تغییر دهید. تا قبل از آن، آیکون رسمی موجود به‌عنوان جایگزین امن استفاده می‌شود و هیچ فایل مفقودی در نصب برنامه وجود ندارد.

## ۲) لودینگ ثابت همه صفحه‌ها

فایل تحویلی اکنون با نام `assets/media/yolda-loading.webm` فعال است. این فایل VP9 با ابعاد ۷۲۰×۱۲۸۰ به‌صورت تمام‌صفحه، بدون برش تصویر و با پس‌زمینه هماهنگ در شروع برنامه و هر تغییر مسیر واقعی نمایش داده می‌شود. متن پایین ویدیو نام صفحه مقصد را اعلام می‌کند؛ جابه‌جایی‌های سریع با توکن رندر از نمایش محتوای مسیر قدیمی جلوگیری می‌کنند.

- `yolda-loading.webm` — فایل اصلی فعال برای شروع برنامه، همه صفحه‌ها و لودینگ AI.
- لودینگ CSS داخلی — fallback خودکار برای Reduced Motion یا خطای ویدیو.

ابعاد پیشنهادی ۷۲۰×۷۲۰ یا ۱۰۸۰×۱۰۸۰ است. برای لودینگ شفاف، WebM با Alpha بدهید؛ نسخه MP4 باید پس‌زمینه بنفش `#5E1A84` داشته باشد چون H.264 شفافیت ندارد.

## ۳) لودینگ پیشنهاددهنده هوشمند

همان فایل رسمی `yolda-loading.webm` هنگام تحلیل درخواست و ساخت پیشنهاد نمایش داده می‌شود؛ متن وضعیت AI در سه مرحله فهم درخواست، بررسی موجودی و رتبه‌بندی تغییر می‌کند. رفتن به نتیجه دوباره لودینگ مسیری را پخش نمی‌کند، چون همان لودینگ AI کل انتظار را پوشش داده است. تجربه Reduced Motion از انیمیشن CSS سبک استفاده می‌کند.

## ۴) فعال‌سازی فایل‌ها

برند محلی و هر دو زمینه لودینگ ویدیویی هم‌اکنون فعال‌اند:

```js
const localAssetSwitches = Object.freeze({
  brand: true,
  pageLoader: true,
  aiLoader: true
});
```

اگر هر ویدیو بارگذاری نشود، سایت خودکار از لودینگ CSS داخلی استفاده می‌کند و متوقف نمی‌شود.

## ۵) فونت دانا

فونت دانای تحویلی اکنون به‌صورت محلی در کل سایت فعال است. فایل‌های WOFF2 استفاده‌شده در `assets/fonts/` عبارت‌اند از:

- `Dana-Regular.woff2`
- `Dana-Medium.woff2`
- `Dana-DemiBold.woff2`
- `Dana-Bold.woff2`
- `Dana-ExtraBold.woff2`
- `Dana-Black.woff2`

وزن‌های ۴۰۰ تا ۹۰۰ در ابتدای `assets/css/tokens.css` تعریف شده‌اند، دو وزن اصلی Preload می‌شوند و همه وزن‌ها برای استفاده آفلاین در Service Worker کش می‌شوند.

## ۶) سایر تصاویر

- بنرها: `assets/images/banners/`
- تصاویر رستوران، فروشگاه و داروخانه: `assets/images/vendors/`
- تصاویر غذا و کالا: `assets/images/products/`
- آواتارها: `assets/images/avatars/`
- آیکون‌های رسمی موجود: `assets/icons/` (نام فایل‌های فعلی را تغییر ندهید)

برای عکس‌ها WebP و برای نسخه‌های خیلی فشرده AVIF مناسب است. راهنمای نسبت و اندازه داخل `assets/images/README.md` قرار دارد.

## چرا GIF نه؟

GIF برای لودینگ ویدیویی توصیه نمی‌شود: حجم بیشتر، رنگ کمتر، شفافیت ضعیف و مصرف پردازنده بالاتری دارد. فایل ویدیوی اصلی را نگه دارید یا همان فایل اصلی را تحویل دهید؛ خروجی مناسب وب باید WebM به‌همراه MP4 fallback باشد. اگر انیمیشن از After Effects و کاملاً برداری است، فایل Lottie JSON نیز گزینه بسیار خوبی است و می‌توان در مرحله بعد به‌جای ویدیو متصلش کرد.
