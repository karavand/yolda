# تصاویر محتوایی یولدا

تصاویر واقعی محتوا را بر اساس نوع در پوشه‌های زیر قرار دهید:

- `banners/` برای بنرهای خانه و کمپین‌ها
- `vendors/` برای کاور و پروفایل رستوران، فروشگاه و داروخانه
- `products/` برای تصویر غذا و کالا
- `avatars/` برای تصویر کاربر، فروشنده و پیک

فرمت پیشنهادی برای عکس‌ها WebP است؛ برای مرورگرهای جدید می‌توان AVIF هم تولید کرد. نام فایل‌ها انگلیسی، کوچک و خط‌تیره‌دار باشد، مانند `romano-margherita.webp`.

تابع تصویر پروژه مسیرهای کامل را پشتیبانی می‌کند؛ بنابراین در `assets/js/data.js` می‌توان مقدار تصویر را از نام آیکون به مسیری مانند `assets/images/products/romano-margherita.webp` تغییر داد.
